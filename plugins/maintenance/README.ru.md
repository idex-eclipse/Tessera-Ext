# Плагин Tessera: Обслуживание

[English version](README.md)

Необязательный плагин Tessera, который напоминает об обслуживании принтера. Интервалы считаются
в **часах печати, числе печатей, календарных днях и километрах филамента**; любую задачу можно
выключить, напоминания начинаются чуть раньше срока, а перед стартом печати Tessera показывает
камеры над столом и всё просроченное. Плагин добавляет вкладку **Обслуживание** на основную
страницу *Machine* через точку расширения `@core/system#tabs`, виджет для дашборда, монитор
уведомлений и гард на запуск печати. Написан на [Lit](https://lit.dev).

## Требования

- Tessera с plugin API **0.12** или новее и `@core/system` **4.0.0** или новее.
  `tessera-ext` не ставит плагин на более старую Tessera.
- Moonraker с историей заданий (она включена по умолчанию): счётчики берутся из
  `server.history.totals`.
- Для проверки стола: камера в Moonraker (`[webcam]` или виджет камеры). Подойдёт любой сервис
  камеры, у которого есть адрес снимка (snapshot).

## Как пользоваться

1. **Первый запуск.** Вкладка открывает короткую форму настройки: проверка стола вкл/выкл, как вы
   моете стол, тип направляющих каждой оси, сопло и редуктор подачи каждого экструдера. Ответы
   выставляют интервалы. Форму можно пропустить (останутся значения по умолчанию) и пройти заново
   из настроек. Пока она не завершена, напоминаний и диалога перед печатью нет.
2. **Задачи.** Карточка показывает прогресс по каждой единице, статус (в порядке, скоро, пора,
   выключено), раскрывающееся пояснение, зачем нужна задача и как выбрать интервал, и кнопки
   результатов. Кнопка спрашивает необязательную заметку, перезапускает таймер и пишет в журнал.
   **Изменить** меняет интервалы, за сколько начинать напоминать, участие в диалоге перед
   печатью, уведомления и сами кнопки.
3. **Цепочки.** Результат может сделать актуальными другие карточки: *Ремни: Скорректировано*
   просит калибровку шейперов, *Сопло: Заменено* — проверку Z-offset и протяжку на горячую.
   Раздел **Цепочки** рисует карточки на поле: карточку тянут за заголовок, точку рядом с
   результатом тянут на карточку, которую он должен запускать, линию выбирают щелчком и удаляют
   клавишей Delete. Ctrl+Z / Ctrl+Y отменяют и повторяют (на Mac Cmd, на любой раскладке). Связь на
   таймерную задачу делает её актуальной сразу, пока вы не нажмёте её собственную кнопку. Если
   ширина меньше 700 px, вместо поля показывается список связей с формой *Добавить связь*.
4. **Перед печатью.** Когда печать запускается из Tessera (Jobs, History, очередь заданий),
   диалог показывает живые кадры камер, просит подтвердить, что стол пуст и лист на месте, и
   перечисляет просроченные задачи. Просроченное никогда не блокирует печать («Всё равно
   начать»); подтверждение стола блокирует, пока проверку стола не выключат. Старт при
   просроченных работах записывается в журнал.
5. **Уведомления.** «Скоро» (запас времени задачи) и «пора» приходят по одному разу за цикл через
   центр уведомлений Tessera, а просроченная задача повторяется после завершённой печати не чаще
   раза в сутки.

### Задачи по умолчанию

| Задача | По умолчанию |
|---|---|
| Проверка стола перед печатью | включена |
| Мойка стола | 7 дней |
| Смазка осей X, Y, Z | 30 дней (самый короткий интервал из выбранных осей) |
| Очистка карбоновых направляющих | выключена, заменяет смазку для карбона |
| Натяжение ремней: *Проверено* / *Скорректировано* | 90 дней; *Скорректировано* запускает калибровку шейперов |
| Калибровка шейперов | только после *Скорректировано* у ремней |
| Сопло: *Проверено* / *Заменено* | 10 км филамента (латунь), 80 км (закалённое); *Заменено* запускает проверку Z-offset и протяжку на горячую |
| Проверка Z-offset, протяжка на горячую | только после *Заменено* у сопла |
| Смазка редуктора подачи | 1000 часов, 500 у планетарного. Категорически нельзя смазывать зубцы, подающие филамент |
| Свои задачи | название, инструкция, любой интервал, любые кнопки |

## Как идёт подсчёт

Moonraker хранит итоги только по всему принтеру. Каждая задача помнит итоги на момент последнего
сброса, поэтому **сброс итогов на странице History не теряет прогресс**. Идущая печать
учитывается до попадания в историю. Нюансы:

- *Печати* — это счётчик заданий Moonraker, он включает отменённые и неудачные.
- Часы и филамент не делятся по экструдерам: если у инструмента сопло или подача напечатали
  меньше (или больше) остальных, поправьте счётчик вручную в редакторе задачи.
- Диалог перед печатью появляется только для печатей, запущенных из Tessera; печати из других
  программ считаются, но не перехватываются. Напоминания от него не зависят.
- Данные хранятся через настройки плагина Tessera, под ключами `printer:<id>:state` и
  `printer:<id>:journal`. Tessera, которая зеркалирует настройки в базу Moonraker (новые версии),
  держит их на принтере, и все браузеры видят одни и те же задачи. Если включить *sync* для этого
  плагина в Настройки → Плагины, все принтеры делят один объект; ключи с id принтера хранят данные
  раздельно.

## Разработка

```
npm install
npm test            # модель, счётчики, цепочки, напоминания, гард и элементы
npm run typecheck
npm run dev         # пересобирает в <Tessera>/extensions/maintenance/ при каждом изменении
npm run pack        # сборка + архив в registry/
```

В `src/core/` нет ни Lit, ни импортов хоста: модель данных, счётчики, оценка, граф цепочек,
напоминания и решение гарда — обычные функции с тестами. В `src/ui/` лежат Custom Elements, в
`src/queue.ts` гард и очередь его диалогов, в `src/monitor.ts` напоминания.

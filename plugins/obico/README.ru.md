# Плагин Tessera: Obico

[English version](README.md)

Необязательный плагин Tessera для [Obico](https://www.obico.io) (ИИ-обнаружение сбоев печати и
удалённый доступ). Написан на [Lit](https://lit.dev).

Работает на двух уровнях:

- **Только через Moonraker.** Работает и с **Obico Cloud**, и со **своим (self-hosted)**
  сервером. Вкладка **Obico** встроенной страницы *Machine* (`@core/system#tabs`) показывает
  привязку, службу `moonraker-obico` и её лог, туннель Obico.
- **Через API сервера Obico.** Нужны **свой** сервер и токен доступа. Этот уровень добавляет
  вероятность сбоя, тревоги, статистику и настройки реакции.

  Сервер Obico не отдаёт CORS-заголовки, поэтому браузер не может обращаться к нему напрямую.
  Каждый запрос к API идёт через прокси сервисов Tessera (`api.services`, API плагинов 0.13),
  который хранит токен на принтере. В Obico Cloud нет личных токенов, поэтому там уровень API
  недоступен.

## Требования

- Tessera с API плагинов **1.0** или новее и `@core/system` **4.0.0** или новее, с
  включённой службой `tessera-ext`. Она включена по умолчанию. Для Tessera с API ниже 1.0
  нужен один `tessera update` на принтере.
- [moonraker-obico](https://www.obico.io/docs/user-guides/klipper-setup/), установленный на
  принтер. Без него вкладка только подсказывает, как его установить.
- Для уровня API: свой сервер Obico и токен доступа.

## Настройка API

1. Откройте `http://<ваш сервер Obico>/admin/oauth2_provider/accesstoken/add/` в админке своего
   сервера. Туда ведёт ссылка **Открыть страницу токенов** во вкладке.
2. Заполните форму:
   - **User**: свой пользователь;
   - **Token**: длинная случайная строка;
   - **Expires**: дальняя дата;
   - **Scope**: `read write`.
3. Сохраните.
4. В Tessera откройте *Machine* → **Obico** → **API Obico**. Введите адрес сервера (он
   подставляется из `moonraker-obico.cfg`) и токен, затем нажмите **Сохранить**.

То же в терминале на принтере: `tessera-ext service set obico obico http://<сервер>`. Команда
спросит токен.

Токен хранится на принтере в `~/.config/tessera/services/`, читать его может только владелец.
В браузер он не возвращается: вкладка показывает только, что токен сохранён.

## Что добавляет

| Где | Что |
| --- | --- |
| *Machine* → вкладка **Obico** | **Moonraker:** состояние привязки, код и страница привязки, **Открыть в Obico**, **Перепривязать**; служба `moonraker-obico`, **Перезапустить** и конец её лога; куда ведёт туннель Obico и строки `[tunnel]`, чтобы он открывал Tessera. **API:** сервер и токен; настройки реакции этого принтера (следить или нет, пауза или только оповещение, чувствительность, ретракт и подъём Z при паузе, выключение хотэндов и стола при паузе); последние события Obico этого принтера |
| Виджет **Обнаружение сбоев** | последний кадр, который проверил Obico, и его полукруглая шкала под ним (зелёная до 33 %, жёлтая до 67 %, красная выше; серая с причиной, когда Obico не следит); в заголовке карточки — переключатель **Не следить за этой печатью** |
| Виджет **Статистика Obico** | 7 дней, 30 дней или 12 месяцев, для этого принтера или всех принтеров аккаунта: печати, завершено, отменено, часы печати, филамент; тревоги, настоящие сбои, ложные тревоги, без ответа |
| Чип быстрого доступа **Obico** | вероятность сбоя активного принтера цветом зоны, глаз, который подсвечивается, пока Obico следит, и краснеет, пока тревога ждёт ответа; клик открывает вкладку |
| Окно тревоги | на любой странице, когда у принтера этой Tessera есть тревога без ответа. Отправляет критическое уведомление и показывает кадр, шкалу и файл. **Это не сбой**: продолжает печать, если Obico поставил её на паузу, и может перестать следить до конца печати. **Отменить печать**: переспрашивает. **Позже**: закрывает окно на время. Пауза, продолжение и отмена идут через Moonraker, поэтому их видят гарды Tessera; ответ записывается в Obico, который на нём учится |
| Карточка fleet | шкала каждого принтера, красная строка и тег фильтра fleet **Тревога Obico**, пока тревога ждёт ответа |
| Баннер печати | **Obico: не следить**: отключает обнаружение сбоев до конца текущей печати |

За один опрос плагин запрашивает у сервера все принтеры аккаунта: раз в 10 с, пока принтер
этой Tessera печатает, иначе раз в 60 с. Это далеко от лимита сервера в 3600 запросов в час.
Принтер Tessera сопоставляется с принтером Obico по id, который moonraker-obico записывает в
базу Moonraker.

## Откуда берутся данные

| Что | Источник |
| --- | --- |
| Сервер, токен привязки (только задан ли он), путь к логу, туннель | `moonraker-obico.cfg` в папке конфигурации, через файловый API Moonraker |
| Код и состояние привязки | макрос Klipper `OBICO_LINK_STATUS` (из `moonraker_obico_macros.cfg`, его подключает установщик) |
| Перепривязка | макрос Klipper `_OBICO_RELINK` |
| Id принтера на сервере Obico | база Moonraker, `obico` / `printer_id` |
| Состояние службы, перезапуск | `machine.system_info`, `machine.services.restart` (служба должна быть в `moonraker.asvc`) |
| Вероятность, кадр, тревоги, настройки реакции | Obico `api/v1/printers/` (и `PATCH`), `acknowledge_alert`, `mute_current_print`, `media/…` |
| Статистика | Obico `api/v1/prints/stats/` и `api/v1/prints/` |
| События | Obico `api/v1/printer_events/` |

Собственный токен агента плагин никогда не показывает и не отправляет.

## Разработка

```sh
npm ci
npm run typecheck
npm test
npm run dev    # пересобирает в <Tessera>/extensions/obico/ при каждом изменении
npm run pack   # собирает и публикует архив в ../../registry/
```

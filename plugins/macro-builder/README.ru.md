# Macro Builder

Необязательный редактор секций `[gcode_macro ...]` на Blockly для Config в Tessera.
Установите `tessera/macro-builder` после обновления Tessera до версии с
`@core/config` 4.1.0 или новее. В редактируемых `.cfg` появится кнопка
конструктора. Blockly загружается только при открытии диалога. Конструктор
занимает весь экран и использует цвета светлой, тёмной и контрастной темы Tessera,
в том числе при переключении темы без закрытия.

Если курсор внутри макроса, открывается он. В остальных местах можно указать
уникальное имя и создать макрос в конце текущего файла. Доступны блоки команд,
вызовов макросов, присваиваний, комментариев, условий, циклов и произвольного
текста/Jinja. Выражения остаются текстовыми. Поле подсказок предлагает известные
команды, макросы, параметры и объекты Klipper. Длинные поля расширяются;
Jinja от `{` до следующей `}` остаётся одним многострочным raw-блоком.
Рядом с именем можно править локальные `variable_*`; отдельные блоки создают
`SET_GCODE_VARIABLE` и `SAVE_VARIABLE`. Команды с Jinja внутри строки остаются
командными блоками, включая обе команды переменных. Новые блоки комментариев
начинаются с `#`. В панели блоков команды переменных показаны кратко, а после
переноса на поле получают редактируемый шаблон команды. При открытии поля ввода
каретка остаётся в конце текста без выделения всего содержимого. Если поставить
её сразу после `=`, подсказки Config появляются без дополнительного ввода.
Config предлагает имена макросов и переменных; после `VALUE=` —
литерал Python с типом известного начального или сохранённого значения.
Новое имя сохраняемой переменной можно ввести вручную. При вводе в блок Config предлагает
свои контекстные подсказки для команд и Jinja. Все подходящие варианты доступны
в прокручиваемом списке. На узком экране кнопка **Блоки**
открывает свёрнутую панель. Выбранные блоки можно перемещать и удалять кнопками.

Когда фокус в конструкторе вне текстового поля, `C` добавляет команду,
`M` — вызов макроса, `Alt+C` — условие, `L` — цикл. Новый блок встаёт после
выбранного или последнего изменённого блока. После добавления условия или цикла
следующая клавиша вставляет блок внутрь его тела. Учитывается физическое положение
клавиш, в том числе при русской раскладке. В полях команд, имени и переменных
клавиши остаются обычным вводом.

**Применить в редакторе** меняет только несохранённый буфер Config. Ctrl+Z,
сохранение, `.bak` и перезапуск остаются в Config. **Отмена** ничего не меняет.
Если исходный буфер изменился, закройте конструктор и откройте снова.

Парсер хранит исходные диапазоны каждого блока. Неизменённые команды,
комментарии, пустые строки и неизвестный Jinja сохраняют исходный текст.
Изменённые распознанные блоки используют отступ текущего макроса.
Произвольный текст остаётся редактируемым.

Для разработки: `npm install`, `npm run typecheck`, `npm test`, `npm run pack`.
Последняя команда записывает архив и хеш в `registry/`. Blockly находится в
отдельном chunk и не загружается вместе с основным модулем.
